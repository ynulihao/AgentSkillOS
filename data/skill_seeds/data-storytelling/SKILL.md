# Data Storytelling

Transform raw data into compelling narratives that drive decisions and inspire action.

## Workflow

1. **Identify the audience** - Determine technical level, goals, and decisions they need to make
2. **Extract the key insight** - Find the single most important takeaway from the data
3. **Choose a story framework** - Select Problem-Solution, Trend, or Comparison (see below)
4. **Build the narrative arc** - Hook → Context → Rising Action → Key Insight → Recommendations → Call to Action
5. **Select visualizations** - Match chart types to data relationships (see Visualization Selection below)
6. **Craft the headline** - Use formula: [Specific Number] + [Business Impact] + [Actionable Context]
7. **Validate** - Ensure the "so what" is clear, uncertainty is acknowledged, and there is a concrete call to action

## Story Frameworks

### Problem-Solution Story
Structure: Hook (quantified pain) → Context (baseline metrics + benchmarks) → Problem (pattern analysis) → Insight (root cause with visualization) → Solution (numbered actions) → Expected Impact (ROI + payback period) → Call to Action (specific ask with budget)

### Trend Story
Structure: Starting Point (baseline + context) → What Changed (timeline of interventions) → Transformation (before/after metrics table) → Key Insight (compound effect) → Going Forward (targets)

### Comparison Story
Structure: The Question (strategic choice) → Side-by-Side Analysis (same dimensions for each option) → Weighted Scoring Matrix (factors × weights → scores) → Recommendation (clear winner + rationale) → Risk Mitigation (top 3 risks + mitigations)

## Visualization Selection

| Data Relationship | Best Chart Type | When to Use |
|-------------------|----------------|-------------|
| Change over time | Line chart | Trends, growth, seasonal patterns |
| Part-to-whole | Pie/donut, stacked bar | Market share, budget allocation |
| Comparison | Bar chart, grouped bar | A/B results, benchmarking |
| Correlation | Scatter plot | Variable relationships |
| Distribution | Histogram, box plot | Spread, outliers |
| Before/after | Side-by-side panels | Impact of interventions |

### Progressive Reveal Technique
Build complexity incrementally across slides: start with a single metric, then layer in growth rates, segment breakdowns, market share, and opportunity zones. Each slide should answer "so what?" from the previous one.

## Presentation Templates

### Executive Summary Slide
```
KEY INSIGHT (1 sentence, quantified)
├── THE DATA (3-4 key metrics, segmented)
└── THE IMPLICATION (3 actions + investment + expected ROI)
```

### Data Story Flow (7 slides)
1. **Headline** - Quantified insight as title
2. **Context** - Current state + benchmarks + gap
3. **Discovery** - Surprising finding + pattern
4. **Deep Dive** - Root cause + statistical significance
5. **Recommendation** - Actions + resources + timeline
6. **Impact** - Expected outcomes + ROI + risks
7. **The Ask** - Specific decision needed + next steps

## Writing Guidelines

**Headlines**: Always lead with the insight, not the topic. "We're Losing $2.4M to Preventable Churn" not "Customer Churn Report."

**Handling uncertainty**: Present confidence intervals, sample sizes, and ranges. Distinguish correlation from causation. Example: "With 95% confidence, impact estimate: $400K-$600K."

**Key principles**:
- Lead with the "so what" - front-load key findings
- Use the rule of three for points and comparisons
- Match vocabulary to audience (avoid jargon for non-technical stakeholders)
- End every presentation with a concrete, actionable ask
