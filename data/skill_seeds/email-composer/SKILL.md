# Email Composer

Draft professional emails tailored to context, audience, and purpose.

## Workflow

1. **Gather inputs** - Purpose, recipient relationship, key points, desired tone
2. **Select structure** - Match email type to appropriate template
3. **Draft** with clear subject, concise body, and explicit call to action
4. **Validate** - Check tone, completeness, and professionalism

## Email Structure

```
Subject: [Specific, actionable subject line]

[Greeting],

[Opening - purpose in first sentence]

[Body - key points as bullets/numbers]

[Closing - clear call to action with deadline if applicable]

[Sign-off]
[Name]
```

## Tone Guide

| Tone | Style | Use For |
|------|-------|---------|
| Formal | No contractions, proper titles, complete sentences | Executives, external partners, legal |
| Professional | Contractions OK, first names, still polished | Colleagues, managers, vendors |
| Casual | Conversational, brief, direct | Close teammates, quick updates |
| Urgent | `[ACTION REQUIRED]` prefix, bold key points, explicit deadline | Time-sensitive requests |

## Common Email Types

### Request for Information
- State what you need upfront
- List specific questions as bullets
- Explain why (helps recipient prioritize)
- Include deadline if applicable

### Follow-up
- Reference the original message/date
- Briefly recap key points
- Offer next step (call, meeting)

### Technical Update / Maintenance Notice
- Lead with impact and timing
- List what's affected
- Specify required actions
- Link to status page or details

### Customer Support Response
- Acknowledge the issue
- Explain what was found
- List actions taken
- Set expectations for resolution

### Meeting Request
- State the purpose
- List agenda items
- Provide time options
- Include estimated duration

### Decline Request
- Thank them for considering you
- Brief reason (optional)
- Suggest alternative if possible

### Apology
- Acknowledge the specific mistake
- List corrective actions taken
- Include preventive measures

## Subject Line Best Practices

**Effective**: "Action required: Submit timesheet by Friday", "Q4 Sales Report - Review needed", "Meeting rescheduled: Kickoff now Thursday"

**Ineffective**: "Update", "Question", "Hello", "Following up"

## Validation Checklist

- [ ] Subject line is specific and actionable
- [ ] Purpose stated in first sentence
- [ ] Key points organized as bullets/numbers
- [ ] Clear call to action or next steps
- [ ] Tone matches audience and context
- [ ] Attachments included if mentioned
- [ ] Recipients correct (To, CC, BCC)
