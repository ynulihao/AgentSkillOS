Create distinctive, production-grade frontend interfaces that avoid generic "AI slop" aesthetics. Output real working code with exceptional attention to aesthetic details.

## Workflow

1. **Understand context** - Purpose, audience, technical constraints
2. **Commit to a bold aesthetic direction** - Pick a specific design tone
3. **Implement** working, production-grade code
4. **Validate** visual quality, responsiveness, and functionality

## Design Thinking

Before coding, commit to a clear aesthetic direction:

- **Purpose**: What problem does this interface solve? Who uses it?
- **Tone**: Choose decisively - brutally minimal, maximalist chaos, retro-futuristic, organic/natural, luxury/refined, playful/toy-like, editorial/magazine, brutalist/raw, art deco/geometric, soft/pastel, industrial/utilitarian
- **Differentiation**: What makes this unforgettable? What will someone remember?
- **Constraints**: Framework, performance, accessibility requirements

Execute the chosen direction with precision. Bold maximalism and refined minimalism both work - the key is intentionality.

## Aesthetics Guidelines

### Typography
Choose fonts that are distinctive and characterful. Pair a display font with a refined body font. **Never** default to Inter, Roboto, Arial, or system fonts.

### Color & Theme
Commit to a cohesive palette using CSS variables. Dominant colors with sharp accents outperform timid, evenly-distributed palettes. Vary between light and dark themes across designs.

### Motion & Animation
Prioritize high-impact moments: one well-orchestrated page load with staggered reveals creates more delight than scattered micro-interactions. Use CSS-only for HTML; Motion library for React. Scroll-triggering and surprising hover states add depth.

### Spatial Composition
Unexpected layouts. Asymmetry. Overlap. Diagonal flow. Grid-breaking elements. Generous negative space OR controlled density.

### Backgrounds & Texture
Create atmosphere: gradient meshes, noise textures, geometric patterns, layered transparencies, dramatic shadows, decorative borders, grain overlays. Never default to solid white/grey.

## Anti-Patterns (Never Do)

- Inter/Roboto/Arial as primary font
- Purple gradients on white backgrounds
- Cookie-cutter centered layouts
- Uniform rounded corners on everything
- Same aesthetic across different designs
- Converging on common choices (e.g., Space Grotesk) across generations

## Implementation Standards

- Production-grade and fully functional
- Visually striking and memorable
- Cohesive with a clear aesthetic point-of-view
- Meticulously refined in every detail
- Match complexity to vision: maximalist designs need elaborate animations; minimalist designs need precise spacing and typography

## Validation Checklist

- [ ] Aesthetic direction is clear and intentional
- [ ] Typography is distinctive (not generic system fonts)
- [ ] Color palette is cohesive with CSS variables
- [ ] Layout has at least one unexpected or memorable element
- [ ] Animations enhance rather than distract
- [ ] Code is functional and production-ready
- [ ] Design would not be mistaken for generic AI output
